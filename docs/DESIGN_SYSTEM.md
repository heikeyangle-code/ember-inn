# EmberInn 壳层重构最终方案（定稿）

> 本文件取代旧版 EmberDS 规格书与 NIGHTVEIL 方向稿（已删除）。
> 一句话：**壳层没有自己的设计体系——主题啥样，壳就啥样；布局全部推倒重来。**
> 配套：REFACTOR_V2_PLAN.md（总纲）、HANDOFF.md（现状账本）。

---

## 一、三条铁律

1. **主题即皮肤**：壳层零自有配色、零品牌色、零内置皮肤、无代号。官方主题 JSON 的每个视觉字段直接映射为壳层的对应位置（§二映射表）；主题没给的角色在壳层不存在。删除 AI 暖金等一切壳层常量色——AI 侧标识一律由 `bot_mes_blur_tint` 派生。
2. **忠实优先，可读兜底**：主题值原样消费；唯一例外是对比度守卫——派生后计算文字与底的亮度差，正文 <4.5:1（大字 <3:1）时把文字向远离底色方向提到达标为止，最小干预，其余不动。守卫是纯函数，进单测穷举异常主题。
3. **浮层有地板**：毛玻璃浮层永远先垫一层主题底色实底、再叠 `blur_strength` 档位的模糊——文字永远坐在已知底上，不赌背后滚过什么内容。`fast_ui_mode` 直接关模糊。

## 二、主题字段消费总表（壳层的全部颜色来源）

| 官方字段 | 壳层落点 |
|---|---|
| `blur_tint_color` | 所有页面底色 |
| `main_text_color` | 主文字 |
| `italics_text_color` | 弱文字（副文本 / 时间戳 / 组题） |
| `underline_text_color` | 链接 / 次强调文字 |
| `quote_text_color` | 强调：选中态 / 当前导航项 / 启用烛火 / 链接高亮 |
| `bot_mes_blur_tint_color` | **内容面**：卡片、海报名牌、弹层、悬浮钮、AI 侧标识 |
| `user_mes_blur_tint_color` | **操作面**：主按钮、激活 chips、选中底、人格当前环 |
| `chat_tint_color` | 「继续对话」英雄卡叠色 |
| `border_color` | 仅官方有边框语义处（卡缘 / 搜索场缘）。**不做装饰线**；分隔靠留白与字阶 |
| `shadow_color` + `shadow_width` | 浮层投影 |
| `blur_strength` | 全部毛玻璃统一强度档 |
| `fast_ui_mode` | 关模糊总开关 |
| `reduced_motion` | 动效降级 |
| `font_scale` | 全局字号缩放 |
| `compact_input_area` / `hotswap_enabled` / `bogus_folders` / `enableLabMode` 等 | 壳层行为开关（透传消费，不丢） |
| `custom_css` / 15 个内容区变量 | 内核区专属，壳层不碰 |

### 二点六、字段三方处置（内核区 / 壳层 / 透传）

- **内核区（WebView，已实现，红线不动）**：15 个 CSS 变量 + custom_css + body 类开关 + chat_display/avatar_style 枚举，逐字官方语义。
- **壳层（本方案新增消费）**：上表「壳层落点」各字段 + 行为开关类。
- **透传保存**：全部字段无损存盘，未知字段保留——导入导出与官方互读不变。
- 数据流唯一：导入 zip/JSON → OfficialThemeManager 无损保存 → derive 纯函数产出壳层令牌 → CompositionLocal 即时下发；主题切换全令牌 lerp 400ms，壳层与内核同秒换装（同一份 JSON，两个消费者）。
- 出厂状态：仅加载既有内置 Glimmer 主题文件作初始数据（现状不变）。此后一切外观随用户导入/切换的主题走，App 不提供、不预置任何"第二套外观"。

## 三、导航与信息架构（全推倒）

**废除**：三域底部 Tab 栏、胶囊指示器、平板 NavigationRail、首页/书架/世界/设置/外观五屏并列结构、设置八分区长列表主页。

**新范式：单画布 + 悬浮主钮**
- 所有壳层页面右下角一枚悬浮主钮（面＝bot tint + blur，无自定义形状语言，48dp 圆形）。
- 点按 → 自下而上弹出四项竖排小栈：**今夜 / 角色 / 世界 / 设置**，当前项 `quote_text_color` 高亮；点击外部或下滑收回。
- 长按主钮 → **全域搜索面板**：一个输入框过滤 角色 / 世界书 / 设置项 / 斜杠命令，任意设置项 ≤2 次操作直达。
- 边缘横滑手势直接切页（复用 SwipeBack 手势基建）。
- 平板 ≥840dp：同一竖栈变左缘悬浮轨 + 列表-详情双栏。
- 聊天页主钮隐藏——那里是官方内核统治区。

## 六、动效

弹簧底座 damping 0.6 / stiffness 500 沿用。规则：
- 页面切换：fade-through（出 160ms / 入 220ms + y 8dp），无横向转场（横滑留给切页手势）。
- 导航栈：自下而上 spring 错峰 20ms；收起一次性回落。
- 弹层：底部滑入 + 背景压暗 240ms；长按菜单 scale .92→1 + haptic light。
- 主题切换：全令牌 lerp 400ms（换装感知的唯一来源）。
- `reduced_motion`：全部降 80ms fade。

## 八、防 bug 门禁

1. **Lint 红线接 CI**：业务组件禁引 MaterialTheme.colorScheme、禁散落十六进制色，必须走主题令牌访问器。
2. **derive 单测穷举**：异常主题（全黑配黑字 / 全白 / 低对比 / 缺字段 / 未知字段）断言守卫触发且输出达标。
3. **无双轨**：删旧不留回退开关；每期删后 grep 悬空引用 + 编译 CI 兜底。
4. **Roborazzi 截图基线**：关键组件 + 各屏基线进 CI，漂移超阈值一票否决。
5. **节奏**：本机不编译；每期 push → CI 全绿才进下期；括号平衡 + 悬空 grep 先自查。

## 十、验收标准（并入旧规格书条款）

1. 导入任意官方主题后：内容区逐字还原（既有能力）+ **壳层自动同装不违和、无一处残留自有配色**。
2. 对比度守卫在最离谱主题下仍保证设置文字可读；`fast_ui_mode` / `reduced_motion` 直通降级。
3. 全部业务组件零 M3 colorScheme 引用、零硬编码色（lint 门禁绿）。
4. 截图回归：新旧并排评审，布局密度与层次感不落下风；推倒项逐一对照 §七确认消失。
5. App 不携带任何预置皮肤 / 代号 / 品牌色；出厂唯一外观来源 = 内置 Glimmer 主题数据文件（现状）。
